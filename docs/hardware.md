# Hardware Notes

| Item | Specification |
| --- | --- |
| Module | ESP32-S3-WROOM-1 N16R8 |
| Processor clock | Up to 240 MHz, per the source article |
| Operating logic voltage | 3.3 V |
| Display | 1.9-inch IPS color TFT, 170 × 320, ST7789 |
| Audio input | Onboard digital microphone |
| Audio output | Audio decoder and power-amplifier circuitry; speaker included only in the speaker/battery bundle listed by the seller |
| USB input | USB-C, 5 V |
| Battery input | 3.7 V lithium battery, MX1.25 2-pin connector; source says USB charging is supported |
| Status light | WS2812 RGB LED |
| Expansion | I²C, UART (MX1.25 4-pin), GPIO |
| Controls | Reset, Boot, volume up, volume down |
| Board size | Approximately 63.5 × 33 mm |

Pin details are in [Getting Started](getting-started.md). Confirm connector orientation, pin names, battery polarity, and electrical limits against the physical board before use.
